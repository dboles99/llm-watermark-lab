# Security Policy

Report vulnerabilities privately to the repository owner. Do not open a public issue containing watermark keys, third-party text, unpublished provider behavior, authentication material, or a working bypass against a deployed verifier.

## Never commit

- watermark keys or payload secrets
- API keys, bearer tokens, connection strings, or `.env` files
- third-party manuscripts or identifiable research participants
- unlicensed paper PDFs
- exported run artifacts containing protected text

## Research safety

Experiments must use public methods, project-owned methods, open implementations, or explicitly authorized provider testing. Findings must identify the exact compatibility level and cannot be converted into misconduct claims automatically.
