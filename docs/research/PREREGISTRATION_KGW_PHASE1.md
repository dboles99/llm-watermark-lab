## 1. Scope and motivation

The product detector currently cannot emit an estimated FPR because no frozen
calibration exists. This study produces the first frozen calibration
manifests under `schemas/calibration-manifest.schema.json` for the `en`
locale, using synthetic and Taiwan public-domain corpora as pipeline
validation material.

**Honest limitation recorded at freeze:** synthetic corpora are explicitly
non-scientific. A calibration built on synthetic text can validate pipeline
mechanics and threshold arithmetic, but it cannot support claims about
real-world human text until licensed real corpora are admitted. The expected
outcome of Phase 1 is a `validated` pipeline with `draft`-status scientific
claims, plus the sample-size evidence needed to plan Phase 2.

## 3. Hypotheses

| ID | Type | Hypothesis | Direction |
|---|---|---|---|
| H1 | Mechanics (already closed) | Author-code parity holds with zero unexplained mismatches on ≥10,000 randomized contexts | one-sided |
| H2 | Confirmatory | Theoretical null z-test at threshold z>4.0 has empirical FPR ≤ 0.5% per locale partition on synthetic negatives | one-sided upper |
| H3 | Confirmatory | Repeated-context masking does not increase empirical FPR relative to naive counting on the same negatives | non-inferiority |
| H4 | Descriptive | Score distributions for `en` and `zh-Hant-TW` synthetic negatives differ materially; no universal threshold is assumed | exploratory |

H2 and H3 are the primary confirmatory tests. H4 motivates the separate
per-locale calibration design but makes no accept/reject decision.

## 4. Estimands

- **E1 (primary):** empirical FPR at fixed threshold z>4.0, per locale, on
  the calibration partition. Reported as an exact one-sided Clopper-Pearson
  95% upper bound (`watermark_lab.statistics.calibration`).
- **E2:** empirical FPR difference between masked and naive scoring on the
  same negatives, with an exact two-sided interval on the paired difference.
- **E3:** TPR at the same threshold on synthetic positives generated by the
  pinned generator with matched configuration (self-verification path).
- **E4:** score distribution shape per locale (descriptive only: mean, SD,
  deciles, per-length-bin counts).

## 5. Sampling design

### 5.1 Independent unit

The independent sampling unit is the **author-document cluster**. For the
synthetic corpus generator (`synthetic-v1`), each `cluster-XXXX` is one
independent unit; all documents within a cluster are dependent replicates.
Interval arithmetic uses cluster counts, never document counts.

### 5.2 Partitions

Four non-overlapping partitions assigned by cluster (never by document):

| Role | Planned clusters (en) | Planned clusters (zh-Hant-TW) |
|---|---|---|
| development | 40 | 40 |
| calibration | 40 | 40 |
| attack-tuning | 20 | 20 |
| final-locked | 40 | 40 |

Documents per cluster: 5. Sentences per document: 8. Generation seeds are
frozen in the corpus manifests (`research/…` not applicable; corpora are
generated by `watermark_lab.corpora` with seeds `20260815` (en) and
`20260816` (zh-Hant-TW) for development/calibration, and dedicated seeds
`20260817`/`20260818` for attack-tuning/final-locked partitions).

### 5.3 Sample size and power

With 40 calibration clusters per locale and zero observed false positives,
the exact one-sided 95% upper bound is 1−0.05^(1/40) ≈ **7.2%**. This is far
above the eventual 0.1% product target, which requires ≥2,995 independent
negatives. **This is the declared, accepted limitation of the pilot**: it
characterizes the operating point approximately and validates the pipeline;
Phase 2 (real corpora, ≥3,000 clusters per locale) is required for any
sub-1% claim. No sub-1% FPR claim may be derived from Phase 1.

### 5.4 Stopping rule

Fixed-sample. All clusters are scored once; no sequential or optional
stopping. Analyses run only after the full calibration partition is scored
and manifests hashed.

### 5.5 Exclusions (frozen)

A document is excluded iff:

1. Tokenization yields <2 tokens (unscoreable); or
2. The exact tokenizer fingerprint fails verification (whole run aborts instead).

No other exclusions are permitted. Exclusion counts are reported per
partition. Post-hoc exclusions are prohibited.

## 6. Multiplicity and error families

| Family | Tests | Correction |
|---|---|---|
| F1 | H2 for en, H2 for zh-Hant-TW | Bonferroni, α/2 each; family-wise α=0.05 |
| F2 | H3 for en, H3 for zh-Hant-TW | Bonferroni, α/2 each; family-wise α=0.05 |
| F3 | All descriptive (H4, E4) | None; labeled exploratory, no accept/reject |

Threshold z>4.0 is the only confirmatory threshold. Threshold grids used for
descriptive ROC curves belong to family F3.

## 7. Analysis plan (frozen)

1. Verify all frozen input hashes; abort on any mismatch.
2. Generate corpora with frozen seeds; hash manifests.
3. Score calibration-partition negatives with the scientific detector
   (`ScientificKgwDetectionService`), recording z-scores, masks, and
   provenance.
4. Compute E1: cluster-level worst-case FPR (a cluster is a false-positive
   cluster iff any document in it crosses threshold) with exact
   Clopper-Pearson upper bounds.
5. Compute E2 as paired cluster-level differences (masked vs naive).
6. Compute E3 on matched synthetic positives.
7. Emit calibration manifests per locale with status `draft` (synthetic
   corpora cannot produce `frozen` scientific status; the manifest semantic
   validator enforces parity binding and locale fallback exactly).
8. Report all exploratory outputs under F3 labeling.

Analysis code: `scripts/run_kgw_calibration.py` (to be added; hashed into
the calibration manifest `analysis_code_sha256` before execution).

## 8. Permissible exploratory analyses

- ROC/TPR curves over threshold grids (F3).
- Score-vs-length plots.
- Repeated-ngram density effects (F3).
- Comparison against the legacy whitespace-tokenized detector for pipeline
  difference quantification (F3; never promotion evidence).
