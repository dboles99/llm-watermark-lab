# KGW Method Reproduction Runbook

## Purpose

Reproduce the KGW-style green-list watermark baseline end-to-end from the reconciled paper spec through deterministic tests.

## Prerequisites

- Python 3.12+
- Repository cloned locally
- Virtual environment created and dependencies installed:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

### 2. Reproduce the golden vector manually

```powershell
.venv\Scripts\Activate.ps1
python -c "
from watermark_lab.adapters.kgm import kgw_green_list, kgw_detect, kgw_seed_from_context
import json

golden = json.load(open('tests/fixtures/kgw_golden.json', encoding='utf-8'))

green = kgw_green_list(
    key=b'TEST_KEY_KGW_V1',
    context=(golden['prev_token'],),
    vocab_size=golden['vocab_size'],
    gamma=golden['gamma'],
    hash_key=golden['hash_key'],
    seeding_scheme=golden['seeding_scheme'],
)
assert green[:20] == golden['green_list_first_20']
print('green first 20:', green[:20])

seed = kgw_seed_from_context(
    key=b'TEST_KEY_KGW_V1',
    context=(golden['prev_token'],),
    hash_key=golden['hash_key'],
    seeding_scheme=golden['seeding_scheme'],
)
print('seed:', seed, 'expected:', golden['seed'])
assert seed == golden['seed']

result = kgw_detect(
    tokens=golden['tokens'],
    key=b'TEST_KEY_KGW_V1',
    gamma=golden['gamma'],
    context_width=golden['context_width'],
    hash_key=golden['hash_key'],
    seeding_scheme=golden['seeding_scheme'],
)
print('detection:', result)
assert result['green_count'] == golden['green_count']
assert result['T'] == golden['T']
assert abs(result['z'] - golden['z_score']) < 1e-12
assert abs(result['p_value_one_sided'] - golden['p_value_one_sided']) < 1e-12
print('Golden vector reproduced exactly.')
"
```

## Two deliberately separate profiles

- `watermark_lab.adapters.kgw` is the internal Python-RNG mechanics
  profile. Its byte-key extension and `random.Random.shuffle` behavior are not
  author-code compatible.
- `watermark_lab.adapters.kgw_author` is the bounded token-ID compatibility
  profile `kgw-author-simple1-torch-2.13.0-cpu-win-amd64-v1`. It refuses to run
  if the exact CPU-only PyTorch build, source profile, operating system, or
  architecture does not match; it never falls back to the Python RNG.

The fixed author oracle fixture is
`tests/fixtures/kgw_author_torch_2_13_cpu_win_amd64.json`. It was generated by
directly executing the official repository at commit
`82922516930c02f8aa322765defdb5863d07a00e` and retains its Apache-2.0
provenance. The randomized differential gate passed 10,000 deterministic
green-list contexts and 1,000 complete token-score sequences with zero
mismatches. The green-list and score stream SHA-256 values are respectively
`0c91b61069ddde44e78937e32d7afaaee1a1a7f146e8c45602eb30ff5abc67d2`
and `256387352663d605f749ce57aa56c5303e5b5e4ea8ef833d29f7258995b51b1b`.

### Run the optional author oracle locally

Install the CPU-only wheel outside the ordinary project dependency set. Do not
substitute a CUDA or PyPI build under the same profile name:

```powershell
$runtime = Join-Path $env:LOCALAPPDATA "watermark-lab-lab/runtimes/torch-2.13.0-cpu"
python -m pip install --target $runtime `
  --index-url https://download.pytorch.org/whl/cpu `
  "torch==2.13.0+cpu"

$author = Join-Path $env:LOCALAPPDATA "watermark-lab-lab/upstream/lm-watermarking"
git clone https://github.com/jwkirchenbauer/lm-watermarking.git $author
git -C $author checkout --detach 82922516930c02f8aa322765defdb5863d07a00e

$env:PYTHONPATH = "$runtime;$PWD/src"
python -m pytest tests/unit/test_kgw_author_compat.py -q
python scripts/verify_kgw_author_parity.py `
  --author-repo $author --cases 10000 --score-cases 1000 --seed 20260814
```

Expected randomized result includes `"status": "passed"`,
`"greenlist_cases": 10000`, `"score_cases": 1000`, and `"mismatches": 0`.
The script verifies the checkout commit and source-file
SHA-256 values before importing author code.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| `ModuleNotFoundError: No module named 'watermark_lab'` | Activate the virtual environment and run `pip install -e .` |
| Rust compile error in `crates/watermark-core` | Run `cargo test`; the PyO3 signature was fixed to use `Vec<u32>` |
| `pytest` collection error | Ensure the repo is installed as editable: `pip install -e ".[dev]"` |
